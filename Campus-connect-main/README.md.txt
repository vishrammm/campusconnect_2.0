 Campus Connect — Database Module

MySQL database with 15 tables supporting all modules of Campus Connect.

 Modules & Tables

- Core: roles, users
-Lost & Found: item_categories, items, item_reports
- Notice Board: notice_categories, notices, notice_attachments
- Clubs & Events: clubs, club_members, events, event_registrations
- Marketplace: listing_categories, listings, listing_inquiries

 How to Import
1. Open MySQL Workbench
2. Server → Data Import
3. Select `campus_connect_backup.sql`
4. Click Start Import
